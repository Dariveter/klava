# Клавиатурное шоу

Мини-сайт для ребёнка: нажимаешь любые клавиши — появляются буквы, эмодзи, цветные формы, кольца, конфетти и звёзды.

## Что лежит в архиве

- `index.html` — полностью самостоятельная версия для GitHub Pages / прямого открытия.
- `kids.js` — версия для **прямого подключения в Tilda**. Она создаёт приложение поверх страницы в Shadow DOM, поэтому стили Tilda и приложения почти не конфликтуют.
- `tilda-embed.html` — готовый код для блока T123.
- `README.md` — эта инструкция.

## Управление

- **Начать игру** — включает fullscreen и пытается захватить клавиатуру.
- Любая клавиша — спокойный визуальный эффект + короткий звук. Элементы остаются на экране 5–8 секунд и плавно затухают.
- **Shift + R** — родительский выход из игрового режима.

## Почему Tilda подключает JS, а не iframe

Для Keyboard Lock важен активный **top-level browsing context**. В iframe захват клавиатуры может быть недоступен.
Поэтому рекомендуемый вариант — Tilda остаётся верхнеуровневой страницей, а `kids.js` с GitHub Pages
монтирует приложение прямо поверх неё.

## Шаг 1 — GitHub Pages

1. Создайте публичный репозиторий, например `keyboard-kids`.
2. Загрузите в корень все файлы из архива.
3. GitHub → Settings → Pages.
4. Source: **Deploy from a branch**.
5. Branch: `main`, folder: `/root`.
6. Дождитесь HTTPS-адреса вида:
   `https://ВАШ-ЛОГИН.github.io/keyboard-kids/`

HTTPS важен для Keyboard Lock API.

## Шаг 2 — Tilda

1. Добавьте блок **T123 → HTML-код**.
2. Вставьте:

```html
<script
  src="https://ВАШ-ЛОГИН.github.io/keyboard-kids/kids.js?v=1"
  defer
></script>
```

3. Замените `ВАШ-ЛОГИН`.
4. Опубликуйте страницу Tilda.

Tilda выполняет HTML/JS/CSS из T123 только на опубликованной странице.

## Если GitHub Pages закэшировал старую версию

После обновления `kids.js` поменяйте:
`?v=1` → `?v=2`, затем `?v=3` и т.д.

## Что именно блокируется

Сайт пытается:
- перейти в Fullscreen API;
- включить Keyboard Lock API;
- перехватывать все дошедшие до страницы клавиши;
- блокировать Tab/Space/стрелки/обычные browser actions;
- блокировать контекстное меню;
- блокировать drag;
- показывать системное предупреждение при случайном закрытии/перезагрузке.

### Но

Веб-страница **не имеет полномочий ОС**. Браузер/операционная система могут сохранить часть критических
комбинаций для себя. Поэтому абсолютная блокировка `Cmd+Tab`, `Alt+Tab`, системных жестов и выхода в другие
приложения достигается только kiosk/детским режимом самой ОС.

## Что легко поменять

В `index.html` или `kids.js`:
- список эмодзи — массив `emojis`;
- цвета — массив `palettes`;
- родительскую комбинацию — `event.shiftKey && event.code === "KeyR"`;
- громкость — `0.08` в `playTone()`;
- убрать звук — удалить `playTone()` из `triggerEffect()`.

## Рекомендация

Для максимально надёжного сценария:
1. открыть опубликованную страницу Tilda в Chrome/Chromium;
2. нажать **Начать игру**;
3. поверх браузера включить kiosk/детский режим самой операционной системы;
4. `Shift + R` оставлять как выход именно из приложения.
